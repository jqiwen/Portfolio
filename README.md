## Tech Stack

`React` `TypeScript` `Vite` `Lucide React` `Cloudflare Workers` `Resend` `GitHub Actions` `GitHub Pages`

## Running Locally

Install the frontend and Worker dependencies:

```bash
npm install
cd worker
npm install
```

Create `worker/.dev.vars` from `worker/.dev.vars.example` and replace the placeholder with a Resend API key intended for local development. Never commit this file.

Start the Worker first:

```bash
cd worker
npm run dev
```

Then start the frontend from the repository root in a second terminal:

```bash
npm run dev
```

Vite proxies `/api/*` to the local Worker on `http://127.0.0.1:8787`. Production continues to use the same-origin `/api/contact` path.

## Contact Worker Deployment

### 1. Configure Resend

1. Create or sign in to a Resend account.
2. In **Resend Dashboard → Domains**, add `jqiwen.com`.
3. Copy the DNS records generated by Resend into the domain's DNS configuration. Use the exact SPF and DKIM records supplied by Resend; do not substitute example values.
4. Wait until Resend reports the domain as verified.
5. Create a Resend API key. A DMARC policy is a recommended follow-up after confirming the existing domain email configuration.

### 2. Configure the Worker secret

From `worker/`, authenticate Wrangler and store the key in Cloudflare's encrypted secret storage:

```bash
npx wrangler login
npx wrangler secret put RESEND_API_KEY
```

`CONTACT_FROM_EMAIL=contact@jqiwen.com` and `CONTACT_TO_EMAIL=kyraoaij@gmail.com` are fixed server-side values in `worker/wrangler.jsonc`. The API key must never be added there or to frontend environment variables.

### 3. Deploy only the API route

The `jqiwen.com` DNS record must be proxied through Cloudflare so the Worker route can run in front of the existing GitHub Pages origin. Then deploy:

```bash
cd worker
npm run generate-types
npm run typecheck
npm test
npm run build
npm run deploy
```

The Worker route is limited to `jqiwen.com/api/*`; normal site requests continue to the existing frontend hosting.

### 4. Verify delivery

After the Resend domain and Worker secret are configured, submit one valid request and confirm exactly one email arrives at `kyraoaij@gmail.com`:

```bash
curl -X POST https://jqiwen.com/api/contact \
  -H "Content-Type: application/json" \
  -d '{"name":"Alice Chen","email":"alice@example.com","message":"Hi Kyra..."}'
```

The email is sent from `Kyra Portfolio <contact@jqiwen.com>`, addressed only to `kyraoaij@gmail.com`, and uses the visitor's validated email only as `Reply-To`. No automatic visitor email is sent.
